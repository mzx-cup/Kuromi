### 2.2 对话锚点机制（P0）

**位置**：`app/services/llm/dialogue_anchor.py`（8.3KB）

**关键设计**：

- 双状态：`consensus`（已确认共识）+ `open_question`（待解决问题）
- 启发式提取（不依赖 LLM 调用,避免循环依赖）：
  - 共识触发词：我明白了 / 原来 / 对了 / I see / Oh I see ...
  - 待解决触发词：还是不懂 / 为什么...？/ I don't understand ...
- 线程安全（`threading.RLock`）
- 按 `(user_id, session_id)` 隔离
- 单例 store + 可插拔持久化（默认 in-memory,生产可换 Redis/DB）
- `render_for_prompt()` 输出可直接注入到 LLM system prompt

**使用示例**：

```python
from app.services.llm.dialogue_anchor import (
    get_anchor_store, extract_from_student_reply, render_for_prompt,
)

store = get_anchor_store()
# 学生答完一道题
consensus, opens = extract_from_student_reply(student_reply, turn=1)
for c in consensus:
    store.add_consensus(user_id, session_id, c, turn=1)
for q in opens:
    store.add_open_question(user_id, session_id, q, turn=1)
# 下一轮对话前
snap = store.snapshot(user_id, session_id)
anchors_text = render_for_prompt(snap)
system_prompt = f"{base_prompt}\n\n{anchors_text}"
```

**测试覆盖**：14 个用例,包括中英文提取 / 线程安全 / session 隔离 / prompt 渲染截断

### 2.3 Agent 决策审计日志扩展（P0）

**位置**：`app/services/audit_log.py`（扩展,不破坏现有 API）

**新增 3 个函数**：

1. **`audit_agent_decision()`** —— 记录单个 Agent 的决策过程
   - 字段：student_id / agent_id / action / trace_id / input_summary / output_summary / reasoning / knowledge_sources / confidence / extra
   - 自动截断（input_summary ≤200 / reasoning ≤500 / knowledge_sources ≤20 个）
   - confidence 范围校验（只接受 0-1）

2. **`audit_pipeline_complete()`** —— 记录一次完整流水线执行
   - 字段：trace_id / agents_run / duration_ms / status / error
   - 用途：回溯沙箱的数据源

3. **`audit_jailbreak_attempt()`** —— 记录越狱/注入尝试
   - 字段：pattern_matched / snippet / classifier_intent / classifier_confidence
   - 用途：安全审计 + 越狱样本积累（喂给意图分类器优化）

**测试覆盖**：9 个用例,包括基础 / 截断 / 范围校验 / 多行写入

### 2.4 越狱检测意图分类器（P0）

**位置**：`app/services/security/intent_classifier.py`（9.5KB）+ `app/services/security/__init__.py`

**关键设计**：

- 4 类意图：`normal` / `injection` / `role_escape` / `overreach`
- 启发式加权评分(不调用 LLM,避免循环依赖)
- NORMAL 反向衰减：减少 false positive(比如"为什么"等学习词会降低越狱置信度)
- 拦截阈值可调（默认 0.60）
- 单例 + 线程安全
- 与现有 pipeline_gate.py L0 正则**互补**(正则快但粗,分类器慢但准)

**意图覆盖范围**：

| 意图 | 覆盖场景 |
| --- | --- |
| injection | 提示词注入(忽略之前的指令、告诉我提示词) |
| role_escape | 角色扮演逃逸(从现在起进入开发者模式、DAN 模式) |
| overreach | 越权数据请求(SQL 注入、查询所有学生数据) |
| normal | 正常学习问题(怎么、为什么、解释) |

**使用示例**：

```python
from app.services.security.intent_classifier import get_intent_classifier
from app.services import audit_log

clf = get_intent_classifier()
result = clf.classify(user_input)
if result.intent.value != "normal" and result.should_block:
    audit_log.audit_jailbreak_attempt(
        student_id=student_id,
        pattern_matched=result.intent.value,
        snippet=user_input[:200],
        classifier_intent=result.intent.value,
        classifier_confidence=result.confidence,
    )
    return {"error": "检测到越权指令,已拦截"}
```

**测试覆盖**：12 个用例,包括中英文/正常学习问题/所有越狱意图/单例/边界

### 2.5 反思日志 Agent（P1）

**位置**：`app/services/agent/reflection_agent.py`（9.5KB）

**关键设计**：

- 3 个固定核心问题（元认知问题，v2.0 建议原文）
  - 你刚才在哪一步卡住了 / 觉得最难?
  - 如果换个条件 / 换种问法,你会怎么做?
  - 你今天学到的最关键的一点是什么?
- 4 个学科变体（math / coding / language / science）
- 5 种触发时机：`CHAPTER_COMPLETE` / `COURSE_COMPLETE` / `SESSION_END` / `EXAM_FINISH` / `WEEKLY_DIGEST`
- 反思深度评分（0-1）：结合回答数量 + 平均长度
- 周报聚合接口：`weekly_summary()`
- 持久化降级：优先 db.save_reflection_entry，失败则降级到日志
- 不阻断主流程（异常捕获 + warning 日志）

**使用示例**：

```python
from app.services.agent.reflection_agent import (
    get_reflection_agent, ReflectionTrigger,
)

agent = get_reflection_agent()
prompt = agent.build_prompt(
    student_id="u1",
    trigger=ReflectionTrigger.CHAPTER_COMPLETE,
    context={"chapter": "递归基础"},
    subject="coding",
)
# 前端弹出 prompt.questions(3-4 道)
# 学生答完后:
entry = agent.record(
    student_id="u1",
    trigger=ReflectionTrigger.CHAPTER_COMPLETE,
    answers={"Q1": "...", "Q2": "...", "Q3": "..."},
    context={"chapter": "递归基础"},
)
# entry.depth_score() 反映反思深度,影响画像
```

**测试覆盖**：13 个用例,包括 3/4 题构建 / 深度评分 / 清洗截断 / 周报聚合

### 2.6 变式题生成器（P1）

**位置**：`app/services/agent/variant_question_generator.py`（12.1KB）

**关键设计**：

- 4 种变式维度：
  - `SURFACE` —— 换数字/单位/物品,骨架不变
  - `SCENARIO` —— 换应用场景(加法→购物找零,乘法→打包...)
  - `CONSTRAINT` —— 加额外条件(限时/多解/反向/画图)
  - `ANGLE` —— 换考察角度(元认知/原理/应用/推广/关联)
- 启发式 + 可选 LLM 增强（llm_call 参数）
- 相似度计算 + 去重(避免与原题重复)
- 单例 + 无状态核心(可并发)

**使用示例**：

```python
from app.services.agent.variant_question_generator import (
    get_variant_generator, VariantDimension,
)

gen = get_variant_generator()
original = {"stem": "小明有 3 个苹果,妈妈又给他 2 个,现在有几个?", "answer": "5"}
variants = gen.generate(
    original,
    knowledge_point="加法",
    n=3,
    dimension=VariantDimension.SCENARIO,  # 换场景
)
# variants 是 3 道不同场景的"小明有3个苹果"题
```

**测试覆盖**：11 个用例,覆盖 4 个维度 / 去重 / 边界 / 单例
