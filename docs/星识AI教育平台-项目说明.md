**星识项目 = 知域成熟教学管理底座 × AI 多智能体引擎 × 苏格拉底式个性化学习闭环。**

将「知域教师端」与「用户可视化数据大屏」整体迁移至星识平台，叠加 AI 能力，贯通"课程生成 → 学习路径规划 → 个性化推荐 → 学情评估"全链路。

## 四、详细结构化版（PRD / 立项文档）

### 4.1 项目背景与目标

将「知域教师端」与「用户可视化数据大屏」整体迁移至「星识项目」，在此基础上深度融合 AI 能力，构建一套覆盖 **课程生成 → 学习路径规划 → 个性化推荐 → 学情评估** 全链路的智能教育系统。

核心要解决的四个问题：

1. 教师备课与课程生产效率低，缺乏系统化 AI 辅助
2. 学生学习路径千人一面，缺乏个性化推荐
3. 学情评估维度单一，缺乏过程性、创新性评价
4. 教学管理数据分散，教师端与学生端体验割裂

---

### 4.2 核心功能模块

#### 4.2.1 AI 问答系统（苏格拉底式引导）

| 维度 | 说明 |
| --- | --- |
| 交互模式 | 围绕知识点进行苏格拉底式层层追问，引导学生自主思考而非直接给答案 |
| 输出形态 | 文字讲义 / 图片说明 / 短视频讲解（多模态生成） |
| 辅助能力 | 学习评估自动生成（多 Agent 协作完成） |
| 教学法 | OBG 学习法 × PBL 学习法 双轨融合 |

#### 4.2.2 课程智能生成（头脑风暴模式）

**生成流程**：头脑风暴 → 计划书 → 执行计划 → 完整课程产出

**一门完整课程包含**：

```
一门完整课程
├── 课程大纲
├── 教学计划 & 教案
├── 课件 PPT
├── 知识图谱
├── 能力图谱
├── 测试项目
├── 教学案例
├── 习题库
├── 问卷调研
└── 配套交付物（面向用户的一套完整资料）
```

**双轨学习法支持**：

- **OBG 学习法**（Outcome-Based Learning，目标导向）
- **PBL 学习法**（Project-Based Learning，项目驱动）

#### 4.2.3 学习画像构建

- **画像构建方法**：多维行为数据采集 → 特征工程 → 动态画像更新
- **画像维度**：
  - 知识掌握度
  - 能力倾向
  - 学习习惯
  - 薄弱点分布
  - 兴趣偏好
- **更新机制**：行为触发 + 周期刷新 + 重大事件即时重算

#### 4.2.4 个性化学习路径与推荐

| 算法模块 | 功能说明 |
| --- | --- |
| 学习路径规划算法 | 基于当前画像 + 目标差距，计算最优学习序列 |
| 课程推荐机制 | 实时匹配最适合的课程 / 资源组合 |
| 个性化资源分发 | 根据画像标签动态调整内容难度与呈现形式 |
| 资源个性化 | 千人千面的内容组合、难度梯度、讲解方式 |

#### 4.2.5 多智能体协同机制（Multi-Agent）

**架构示意**：

```
                ┌──────────────────┐
                │  Orchestrator    │  ← 任务分解与调度
                └────────┬─────────┘
                         │
        ┌────────────────┼────────────────┐
        │                │                │
   ┌────▼─────┐    ┌─────▼─────┐    ┌─────▼─────┐
   │ 问答Agent │    │ 评估Agent │    │ 内容Agent │
   │ 苏格拉底 │    │ 评分创新  │    │ 讲义课件  │
   └────┬─────┘    └─────┬─────┘    └─────┬─────┘
        │                │                │
        └────────────────┼────────────────┘
                         │
                ┌────────▼─────────┐
                │   推荐Agent      │  路径 + 资源匹配
                └────────┬─────────┘
                         │
                ┌────────▼─────────┐
                │   审核Agent      │  防幻觉 + 安全校验
                └──────────────────┘
```

**协作模式**：

- 任务链式传递 + 交叉验证 + 循环迭代优化
- 多 Agent 联合评分机制，减少单一模型偏差

**Agent 角色分工**：

| Agent | 职责 |
| --- | --- |
| 问答 Agent | 苏格拉底式引导，文字 / 图片 / 视频多模态输出 |
| 评估 Agent | 学习成果多维评分，含过程性与创新性 |
| 内容 Agent | 讲义、课件、案例、习题等内容生成 |
| 推荐 Agent | 学习路径规划与课程 / 资源个性化匹配 |
| 审核 Agent | 防幻觉校验、事实溯源、安全边界把关 |

#### 4.2.6 评分与创新评价

- 多维度综合评分：**知识 / 能力 / 过程 / 创新** 四维一体
- Agent 协作打分 + 人工校准双保险
- 强调**创新维度**评价，鼓励学生发散思维与项目实践

#### 4.2.7 知识库与安全体系

| 层级 | 说明 |
| --- | --- |
| 知识库 | 领域知识索引 + RAG 检索增强生成 |
| 防幻觉机制 | 引用溯源 + 置信度标注 + 事实校验 Agent |
| 安全边界 | 内容过滤 + 权限隔离 + 敏感词拦截 |
| 循环优化 | 用户反馈 → 画像更新 → 路径重算 → 内容迭代 |

**循环迭代闭环**：

```
用户反馈 ──→ 画像更新 ──→ 路径重算 ──→ 内容迭代
   ↑                                        │
   └────────────────────────────────────────┘
```

#### 4.2.8 数据可视化大屏（原知域迁移）

**教师端**：

- 班级学情总览
- 课程效果分析
- 学生个体追踪
- 教学决策辅助

**学生端**：

- 个人学习画像
- 进度热力图
- 能力雷达图
- 成就系统

### 4.4 创新点

1. **苏格拉底式 AI 问答**：不直接给答案，引导学生自主建构知识
2. **多 Agent 协同评分**：消除单一模型偏差，过程性与创新性并重
3. **课程全自动生成链路**：从头脑风暴到完整课程包的一站式输出
4. **OBG × PBL 双轨融合**：目标导向 + 项目驱动的混合教学模式
5. **画像驱动的个性化闭环**：实时反馈、动态调整、循环优化
6. **教学底座无缝迁移**：复用知域成熟体系，降低落地成本

---

### 4.5 价值主张

**For 教师**：
- 备课效率提升，课程生产自动化
- 学情数据全景掌握，精准教学干预
- 教学效果可量化、可追溯

**For 学生**：
- 千人千面的学习路径
- 多模态沉浸式学习体验
- 创新能力与过程性成长被看见

**For 平台**：
- 教学管理 + AI 能力 + 数据可视化三位一体
- 可扩展的多 Agent 架构支撑未来场景
