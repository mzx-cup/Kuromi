## 设计方向

**星座棱晶（Constellation Prism）** — 以星图为骨架、棱晶折射为细节的深色奢华学习仪表盘。

融合两种美学基因：
- **星座图（Constellation Map）**：深靛蓝夜空 + 精密星座网格连线 + 星点节点标记 + 天文坐标装饰
- **棱晶折射（Crystalline Prism）**：卡片切角 clip-path + 角落七彩棱镜微光 + 彩虹渐变色彩系统

整体调性：大胆、精致、有艺术感，契合"星识 Star-Learn"品牌名，无 emoji 图标，全部使用 SVG/CSS 图形。

## 色彩系统

所有颜色通过 `tokens.css` oklch 变量驱动，0 硬编码颜色值。下列色值为视觉参考，实现时需映射为 tokens.css 语义变量。

| 角色 | 参考色值 | 用途 |
|------|------|------|
| 主色-靛蓝 | `#7098d8` | 主要交互、节点标记、边框 |
| 辅色-青 | `#68c0c8` | 专注计时、进度指示、链接 |
| 辅色-紫 | `#b8a0e0` | 知识生态、学习相关卡片 |
| 辅色-金 | `#d8b070` | 统计数据、成就、强调 |
| 背景-深空 | `#050a1a` | 页面底色 |
| 卡片-深靛蓝 | `~#0a1024` | 卡片背景（半透明叠加） |
| 文字-主 | `#dce4f4` | 标题、重要文字 |
| 文字-次 | `#5580a8` | 正文、描述 |
| 文字-弱 | `#507098` | 注释、坐标标注 |

彩虹渐变序列（用于进度环/棱镜折射/渐变文字）：
```
靛蓝 #7098d8 → 青 #68c0c8 → 紫 #b8a0e0 → 金 #d8b070
```

## 页面背景系统（四层叠加）

```
Layer 1: 深空渐变
  - 多个径向渐变椭圆叠加，模拟星云光斑
  - 位置：左上靛蓝光斑、右下紫光斑、右上青光斑

Layer 2: 星场
  - 散布的微小星点 (0.4–1.2px)，明暗不一
  - 2–3 颗亮星带十字星芒（细线交叉）

Layer 3: 星座网格
  - 贯穿全页的微光连线，使用 SVG line + linearGradient 淡入淡出
  - 连线交汇处为星座节点（2–3.5px 圆点）
  - 不透明度约 0.08–0.12

Layer 4: 星云光斑
  - 大尺寸径向渐变柔光团
  - 不透明度极低 (~0.02–0.03)
```

## 卡片设计规范（六层堆叠）

### 形状
- `clip-path: polygon(12px 0, 100% 0, 100% calc(100% - 12px), calc(100% - 12px) 100%, 0 100%, 0 12px)` — 12px 切角

### 边框层次（box-shadow 模拟多层光学镀膜）
```css
box-shadow:
  0 0 0 1px rgba(70,110,170,0.08),   /* 外层微光 */
  0 0 0 2px rgba(70,110,170,0.04),   /* 中层扩散 */
  0 0 0 3px rgba(70,110,170,0.02),   /* 内层晕染 */
  0 4px 40px rgba(0,0,0,0.45),       /* 底部阴影 */
  inset 0 1px 0 rgba(255,255,255,0.015); /* 顶部微光 */
```

### 棱镜折射角（每张卡 1–2 个角落）
- 在卡片角落放置一个溢出隐藏的容器
- 内部用 `linear-gradient` 模拟棱镜折射光
- 使用 `clip-path: polygon(...)` 三角形裁剪
- 配色根据卡片类型变化：
  - 蓝色卡：蓝→青渐变折射
  - 紫色卡：紫→蓝渐变折射
  - 金色卡：金→紫渐变折射
- 每角双层叠加：浓淡两色，增加深度

### 卡片配色方案

| 卡片类型 | 边框色调 | 棱镜折射色 | 节点色 |
|----------|---------|-----------|--------|
| 学习路线 | 靛蓝 `rgba(70,110,170,*)` | 蓝→青→紫 | #80a8e0 |
| 专注计时 | 青 `rgba(80,150,180,*)` | 青→紫→金 | #68c0c8 |
| 知识生态 | 紫 `rgba(120,90,180,*)` | 紫→蓝→青 | #a898e0 |
| 统计数据 | 金 `rgba(180,140,90,*)` | 金→紫→青 | #d8b070 |

## 组件设计规范

### 1. 顶部导航栏
- 半透明深色底 + backdrop-filter 模糊
- 左侧：星形 SVG logo（八角星 + 中心圆）+ "星识 Star-Learn"
- 右侧：搜索框（圆角 pill）+ 心流指数 + 通知 + 用户头像
- 底部微光分割线

### 2. 左侧图标导航（48px）
- 纯图标 + hover 展开
- 图标使用 SVG 线条风格（星座图风格细线）
- 当前激活项有靛蓝微光背景

### 3. 标签页栏
- 圆角 pill 容器，半透明底
- 激活标签：靛蓝微光背景 + 加粗文字
- 非激活：弱色文字

### 4. 星座节点标记
- 多层同心环（2–3 环，不同透明度/虚线）
- 中心实心圆点 + 外圈光晕
- 部分节点带小光点卫星
- 配套天文坐标标注文字（RA/Dec 格式装饰）

### 5. 专注计时器环（三层天文环）
```
外层：光晕环 (opacity 0.06, 虚线刻度)
中层：天文标记环（NESW 四个方位点标记）
内层：彩虹渐变进度环（靛蓝→青→紫→金 conic-gradient）
中心：深色圆底 + 数字 + 单位
```
- 环外可选配倾斜轨道环装饰（椭圆 + 光点）

### 6. 知识生态柱状图
- 7 根柱状条，高度不一
- 渐变色柱（紫→蓝→青→金）
- 高柱顶部有星光标记点
- 底部科目简称标注
- 彩色图例行（已掌握/学习中/待复习）

### 7. 数据统计卡片
- 大数字使用彩虹渐变色 `-webkit-background-clip: text`
- 下方指标网格（3 列等宽，微底纹背景）
- 渐变分割线（横线 + 星光点标记）

### 8. 趋势迷你图（SVG polyline）
- 7 日学习趋势折线
- 每个数据点一个彩色圆点
- 最后一天（今日）用金色强调
- 底部星期标注
- 淡色网格参考线

### 9. 标签 Pill
- 半透明彩色底 + 同色系微光边框
- 小圆角 (5px)
- 配色跟随卡片色调

### 10. 分割线
- 渐变透明横线（一侧有色、一侧消失）
- 线上可选星光点标记

### 11. 右侧面板
- 星历日历：日期数字大号加粗 + 节点数标注
- 星讯/动态列表
- 快捷入口

## 技术方案

### CSS
- 单一文件 `css/hub.css`，完全重写
- 目标 < 2500 行
- 0 硬编码颜色值 — 100% 使用 tokens.css CSS 变量
- 使用 CSS Grid 做卡片布局，Flexbox 做组件内部布局
- 卡片切角使用 `clip-path: polygon()`
- 棱镜折射角使用 `linear-gradient` + `clip-path` 三角形裁剪
- 多层边框使用 `box-shadow` 堆叠（非 `outline` 或 `border`）
- 所有动画保留（fadeInUp、glowPulse、shimmer 等）

### HTML
- 语义化结构
- 移除所有内联 style 中的硬编码颜色
- 保留现有 data-* 属性体系

### 现有特效保留与适配
- 数据粒子（data particles）：保留，配色适配新色彩系统
- 光标光晕（cursor glow）：保留
- 涟漪效果（ripple）：保留
- 卡片 shimmer 扫光：保留，光泽色适配靛蓝色系
- 3D 倾斜（3D tilt）：保留
- 浮动微尘（floating dust）：保留
- 卡片呼吸光（breath glow）：保留，配色适配

### JavaScript
- 保留现有全部功能模块（FocusTracker、DailyRoute、StudyHall、Kanban、KnowledgeEco、Toast 等）
- 保持 localStorage 数据持久化
- Canvas 图表（趋势图、热力图）样式适配新色彩系统

### 响应式断点
- `≥1400px` — 完整三栏
- `≥1024px` — 右侧面板折叠
- `≥768px` — 左侧导航折叠
- `<768px` — 单栏
