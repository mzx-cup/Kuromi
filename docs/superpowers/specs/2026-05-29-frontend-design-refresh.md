# 前端设计改造 — 去 AI 味 · 轻快活泼学院风

**日期**: 2026-05-29
**范围**: 6 个核心页面（首页对话、Hub 中枢、课程中心、课程学习页、视频播放页、个人中心）
**目标**: 去除霓虹科幻感，建立温暖通透的学院风格，默认亮色为主

---

## 1. 整体气质

三个关键词：**温暖、通透、有呼吸感**。

- 页面底色是微微偏暖的米白，不是冷冰冰的纯白
- 卡片有存在感但不厚重——像纸质索引卡轻轻放在桌面上
- 圆角偏大但不玩具感，文字清晰有礼貌
- 暗色模式保留，配色映射到对应色阶

## 5. 动画与微交互

### 5.1 缓动曲线（3 种）

| Token | 值 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(0, 0, 0.2, 1)` | 绝大多数过渡 |
| `--ease-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | 弹窗进出、侧栏展开 |
| `--ease-standard` | `0.15s ease` | hover 颜色/边框变化 |

砍掉：弹簧曲线 `cubic-bezier(0.34, 1.56, ...)`、`transition-delay` 逐元素出现、无差别 `transition: all`。

### 5.2 加载动画分级

| 场景 | 动画 | 说明 |
|---|---|---|
| 系统首次进入 | 3D 地球旋转 + 星星（保留现有） | 品牌记忆点 |
| 页面间跳转 | 品牌 logo 旋转环 + "加载中..." 脉冲文字 | 简洁安静，0.6s |
| 内容块加载 | 骨架屏（opacity 呼吸动画，1.5s） | 无独立 loading 层 |

### 5.3 组件交互

| 组件 | 效果 |
|---|---|
| 卡片 hover | `translateY(-2px)` + `shadow-xs → shadow-sm` |
| 按钮 hover | 背景色过渡 0.15s |
| 弹窗进出 | `opacity + scale(0.95→1)`，0.2s，`--ease-in-out` |
| Toast | 右侧滑入 + 淡入 0.3s，3 秒自动消失 |

## 6. 组件规范

### 6.1 按钮

| 类型 | 样式 |
|---|---|
| 主按钮 | 暖橙实底 `--brand-500`，白字，`radius: 8px`，`padding: 10px 20px`，`font: 500 15px` |
| 次按钮 | 透明底 + 1px 暖橙边框，暖橙字，hover 变 5% 暖橙底 |
| 文字按钮 | 无背景无边框，暖橙字，hover 加 5% 暖橙底 |

### 6.2 卡片

- 背景纯白（亮色）/ `--neutral-100`（暗色），不毛玻璃
- 边框 1px `--neutral-200`，圆角 14px，padding 16px
- Hover：`translateY(-2px)` + `shadow-sm`，边框变 `--brand-300`

### 6.3 输入框

- 背景 `--neutral-100`，边框 1px `--neutral-200`，圆角 8px，padding 10px 14px，字号 15px
- Focus：边框变 `--brand-500`，无外发光
- Placeholder：`--text-placeholder`

### 6.4 导航栏

- 高度 56px
- 背景 `--surface-nav` + `backdrop-filter: blur(12px)`（仅此处保留毛玻璃）
- 底部 1px `--neutral-200` 边框
- 无阴影

### 6.5 Toast

- 右下角固定，距底 24px 距右 24px
- 白色底 + 1px 边框 + `shadow-md`，圆角 10px
- 左侧 3px 色条：success=teal / error=rose / warning=amber / info=brand
- 动画：从右滑入 + 淡入 0.3s，3 秒自动消失

### 6.6 弹窗 (Modal)

- 遮罩：`rgba(28,25,23,0.4)` + `blur(6px)`
- 弹窗本体：白色，圆角 16px，`shadow-lg`
- 标题栏：padding 20px 24px + 底部分割线
- 内容区：padding 24px
- 按钮栏：padding 16px 24px，按钮靠右，主按钮在右
- 关闭按钮：右上角 36px 圆形灰色图标

### 6.7 空状态 (Empty State)

- 居中，顶部 48px 图标（`#d6d3cc`），标题 16px（`#57544e`），描述 14px（`#a8a59e`）
- 操作主按钮在描述下方 16px

### 6.8 骨架屏 (Skeleton)

- 浅灰 `#e7e5e0` 色块 + opacity 呼吸动画（0.5→1→0.5，1.5s）
- 文字行：圆角 4px 长条，宽度 60%-90% 随机

### 6.9 标签/徽章 (Badge)

- padding 2px 10px，圆角 999px，字号 11px
- 进行中：暖橙底 + 暖橙字
- 已完成：teal 底 + teal 字
- 未开始：浅灰底 + 灰色字

## 9. 实施策略

**方案 A：渐进式改造**——保留现有架构，重写 CSS 变量和样式。

优先级顺序：
1. `index.css` / `hub.css` 的主题变量重写（影响范围最大）
2. 6 个目标页面的 CSS 逐页改造
3. 通用组件样式（弹窗/Toast/按钮等）统一
4. `theme.js` 适配新变量
5. 暗色主题映射验证

**Token 迁移策略**（新老命名共存）：
- 新 token 体系（`--brand-*`、`--neutral-*`）作为新增变量写入，旧 token（`--primary`、`--accent` 等）映射到对应的新值
- 这样已有的 class 和样式不会断裂，逐步替换引用而不需要一次性全部改完
- 最终目标：所有组件引用新 token，删除旧 token 定义

**砍掉清单**：
- `--neon-*` 变量全部删除
- 弹簧动画曲线删除
- 毛玻璃效果仅在导航栏保留
- `letter-spacing` 微调清除
- `transition-delay` 逐元素动画删除
- 过度阴影/光晕删除
