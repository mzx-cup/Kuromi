## 布局骨架

```
┌──────────────────────────────────────────────────┐
│  顶部导航栏 (logo · 搜索 · 主题切换 · 用户菜单)    │
├────┬───────────────────────────────────┬──────────┤
│    │  [总览] [学习] [工具] [数据]       │          │
│ 左  │                                   │  右      │
│ 侧  │  当前标签页内容（卡片网格）        │  侧      │
│ 图  │                                   │  信      │
│ 标  │                                   │  息      │
│ 导  │                                   │  面      │
│ 航  │                                   │  板      │
│    │                                   │          │
├────┴───────────────────────────────────┴──────────┤
│  响应式: ≥1400 三栏 / ≥1024 右侧折叠 / ≥768 左侧折叠 / <768 单栏  │
└──────────────────────────────────────────────────┘
```

- **左侧栏 (48px)**：纯图标导航，hover 展开文字标签。放：首页、学习、工具、数据、设置 等核心入口
- **中央主区**：标签页切换，4 个标签各自承载独立内容区
- **右侧面板 (200px)**：常驻信息 — 今日日历、待办任务、标签云、快捷入口

## 卡片设计规范

混合风格卡片，使用 tokens.css 变量驱动：

- **背景**: `var(--surface-glass)` — 半透明深色
- **边框**: `var(--border-glass)` — 微光边框
- **悬停**: `var(--surface-glass-hover)` + `var(--border-glass-hover)` 品牌色边框
- **阴影**: `var(--shadow-sm)` → hover 时 `var(--shadow-md)`
- **圆角**: `var(--radius-md)` (14px)
- **间距**: 内边距 `var(--space-lg)` (24px)，卡片间距 `var(--space-md)` (16px)
- **过渡**: `var(--transition-base)` (0.25s ease-out)
- **标题**: `var(--text-heading)`，正文 `var(--text-body)`

## 技术方案

### CSS（目标 < 2500 行）
- **单一文件** `css/hub.css`，删除 hub-refined.css / hub-perfect.css / hub-winmoes.css
- **0 硬编码颜色值** — 100% 使用 tokens.css 中的 CSS 变量
- 使用 CSS Grid 做卡片布局，Flexbox 做组件内部布局
- 4 个响应式断点：
  - `≥1400px` — 完整三栏
  - `≥1024px` — 右侧面板折叠为底部抽屉
  - `≥768px` — 左侧图标栏折叠为顶部标签
  - `<768px` — 单栏，标签页改为下拉切换

### HTML
- 语义化结构，section/article/nav 标签
- 移除所有内联 style 属性（颜色/尺寸类），统一由 CSS 管理
- data 属性驱动主题和交互（`data-tab`、`data-theme` 等）

### JavaScript
- 模块化重构 hub.js：
  - `TabManager` — 标签页切换、URL hash 同步
  - `CardRenderer` — 动态卡片渲染
  - `ChartRenderer` — Canvas 图表（趋势图、热力图）
  - `FlowTracker` — 心流分数计算、专注计时
  - `KanbanManager` — 看板拖拽
  - `StudyHall` — 自习室同伴匹配
  - `KnowledgeEco` — SM2 知识生态
  - `Toast` — 通知系统
- 保持 localStorage 数据持久化
