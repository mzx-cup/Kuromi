## 1. 项目背景与审计结论

### 1.1 审计范围

依据《星识AI教育平台-项目说明.md》v1.0 文档中的六大能力模块 + 《星识AI教育平台-项目完善建议.md》v1.0 中的 P0/P1/P2 共 32 项补强建议，逐项对照实际代码实现。

### 1.2 审计关键发现

**结构性缺口（必须补齐才能兑现文档承诺）**：

1. **多 Agent 五大角色未命名实体化**：文档要求"问答Agent / 评估Agent / 内容Agent / 推荐Agent / 审核Agent"，项目实际只有 ProfilerAgent / PlannerAgent / DocumentGeneratorAgent 等 11 类，**没有"推荐Agent""审核Agent"命名类**
2. **Orchestrator → 多 Agent 链式协同未接通**：`MasterController.execute()` 是固定 pipeline，不是链式
3. **Qdrant 向量库 upsert 是 `NotImplementedError`**：`app/services/kb/ingestion.py:22-34` 抛 `NotImplementedError`，RAG 检索路径断链
4. **越狱检测完全缺失**：审计日志只记录拦截事实，无识别算法
5. **教师-AI 协同工作台未实现**：教师端只有 CRUD，没有 AI 协作面板
6. **遗忘曲线 / 间隔复习调度未实现**：`knowledge_nodes` 表 schema 预留但无算法
7. **实时微画像更新未实现**：仅 `/api/v2/telemetry` 端点存在，画像权重未真正在线更新
8. **"为什么推这个"前端可视化解释层缺失**：字段存在但 `personal.html` 未充分渲染

### 1.3 模块评分表

| 模块 | 当前实现度 | 主要缺口 | 目标实现度 |
|---|---|---|---|
| AI 问答引擎（苏格拉底+多模态） | 85% | 缺强制 ≥N 轮追问 + 多模态输入 | 100% |
| 课程智能生成（OBG/PBL + 9 件套） | 90% | brainstorm 未持久化 + 缺变式题 + 缺反思日志 | 100% |
| 学习画像与个性化路径 | 75% | 缺遗忘曲线 + 缺实时微画像 + 解释层 UI 缺失 | 100% |
| 多 Agent 协同机制 | 70% | 缺 5 大命名角色 + 链式协同未接通 + Critic Agent 缺失 | 100% |
| 数据可视化大屏 | 75% | 缺教师-AI 工作台 + 班级 AI 汇总 + 个人画像 4 卡面板 | 100% |

### 3.3 关键架构决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 五大 Agent 命名 | **新增 `RecommendAgent` + `AuditAgent`**，3 个已有 Agent 改名挂载到命名空间（`SocraticEvaluatorAgent` → `QaAgent` / `EvaluationAgent` → `EvaluateAgent` / `DocumentGeneratorAgent` → `ContentAgent`），保留旧类名做 alias | 兑现文档原文 5 角色 + 不破坏现有调用方 |
| Orchestrator 链式协同 | **新增 `OrchestratorChain` 类**，支持"任意 Agent → 任意 Agent"的链式重试 + 共识投票 | 不破坏现有 `MasterController.execute()` pipeline，向后兼容 |
| Qdrant 接入 | **`ingestion._persist_to_qdrant` 直接调用 `QdrantClient.upsert`**，删除 `NotImplementedError` | 立刻生效 |
| 越狱检测 | **正则 + LLM 二次判定双层**（L0 拦截 ≤50ms 正则，L1 异步 LLM 校验 ≤2s）| 性能+准确性兼顾 |
| 遗忘曲线 | **SM-2 + 个人遗忘率拟合**（基于 quiz 历史反推个人 `stability` 参数）| 比纯 Ebbinghaus 个性化更强 |
| 教师工作台 | **复用 `teacher-dashboard.html`**，新增"AI 建议"Tab + `/api/teacher/ai-suggestions` + `/api/teacher/suggestion/{id}/act` 端点 | 不重建页面 |
| 持久化 brainstorm | **新建 `brainstorm_sessions` ORM 表** + Alembic 迁移 | 沿用 Repository 抽象 |
| sandbox 执行 | **subprocess + timeout 5s**（不引入 Docker 依赖）| 部署轻量，5s 限制防资源滥用 |

### 6.5 风险与回滚预案

| 风险 | 触发条件 | 回滚动作 |
|---|---|---|
| Qdrant upsert 写入失败 | 连续 10 次 upsert 异常 | try/except 包装 + 入 fallback queue（SQL 仍写） |
| 越狱检测误杀 | 误杀率 >5% | L1 LLM 二次判定开启（默认只跑 L0 正则） |
