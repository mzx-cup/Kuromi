## 一、现状盘点（已实现的能力）

### 1.2 多智能体编排（v1.0 说 5 个，实际 9 个）

`app/api/agent_orchestration.py` 注册的 9 个 Agent：

| Agent | 阶段 | 工具 |
| --- | --- | --- |
| EchoAgent | pre | 登录问候 |
| ProfilerAgent | main | 6 维画像 / 情绪识别 / 盲区检测 / 认知超载干预 |
| PlannerAgent | main | 知识图谱 / 内容类型路由 / 难度梯度 |
| DocumentGeneratorAgent | parallel | Markdown 渲染 / 章节拆分 / 插图占位 |
| ExerciseGeneratorAgent | parallel | 题目模板 / 难度档位 / 答案解析 |
| MindmapGeneratorAgent | parallel | 概念抽取 / 层级归并 / SVG 渲染 |
| VideoContentAgent | parallel | B 站检索 / 片段切片 / 字幕校对 |
| ResourcePushAgent | post | 用户偏好匹配 / 推送时机 / 去重 |
| EvaluationAgent | post | 行为打分 / 掌握度更新 |

**Pipeline**: `pre → main → parallel(并发 4) → post`，通过 SSE 流式推送，trace_id 全程追踪。

### 1.3 苏格拉底实现（v1.0 描述 + 实际更强）

- `app/services/persona_socratic_rules.py` —— **强度可配**（0/0.2/0.5/0.8/1.0 五档）
- `app/services/llm/socratic_response.py` —— 端到端苏格拉底响应管线（KB 检索 → Prompt 注入 → LLM 流式 → 反幻觉解析 → 重试）
- `app/services/tutor_engine/pipeline_gate.py` —— **L2 苏格拉底追问** 是 4 层管线之一

### 1.4 防幻觉体系（v2.0 三级，实为四级）

`app/services/tutor_engine/hallucination_guard.py` 已实现：

| 层 | 实现 | 文件 |
| --- | --- | --- |
| L1 | 教材引用锚定校验 | `hallucination_guard.py:_validate_citations` |
| L2 | 外部来源（Web Search）交叉校验 | `hallucination_guard.py:_check_web_consistency` |
| L3 | 代码沙箱执行 | `hallucination_guard.py:_execute_code` |
| L4 | 置信度决策（拦截/追加免责声明） | `hallucination_guard.py` |

可信外部域名白名单已经内置（github / stackoverflow / csdn 等 30+ 个）。

### 1.5 输入安全（v2.0 越狱检测，已有部分）

### 1.6 知识体系

- **KB**：`app/services/kb/` —— embeddings + Qdrant + citation_retriever + ingestion + splitter

### 1.7 学习画像与路径

## 四、本次不补的（说明理由）

- **家长数字孪生报告**：需要月度定时任务 + 报告模板 + 多维度数据汇总，单次会话内做不完
- **多模态 OCR 输入**：要接外部 OCR 服务（百度/腾讯/自研），配置 + 集成成本高
- **学科专用 Agent**：要重构 personas 系统，超出本次范围
- **决策回溯沙箱**：要重放引擎，独立大模块
- **GDPR 合规流程**：涉及产品流程和法务，超出代码范畴

## 五、整体建议

1. **v1.0 完善建议书需要重写**：因为大多数 P0 想法已经实现了，建议书应该改成"v2.x 增强路线图"，聚焦真正还差的 ~15 项

3. **建议清理 legacy 单体**（`main.py` 437KB / `db.py` 285KB / `agents.py` 73KB）：同时存在新旧两套架构，长期维护成本高
4. **本次会话内**：实施上述 6 项 P0/P1 缺口，写测试覆盖
