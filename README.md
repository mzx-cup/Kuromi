# 星识 Star-Learn

> **个人智能学习中枢** — 基于多智能体协同的新一代个性化学习系统
>
> 答辩索引 · 一页纸进入点

---

## 这是什么

**星识 (Star-Learn)** = 知域成熟教学管理底座 × 多智能体引擎 × 苏格拉底式学习闭环。

把「知域教师端」与「学生可视化数据大屏」整体迁移到星识平台，叠加 AI 能力，
贯通「**课程生成 → 学习路径规划 → 个性化推荐 → 学情评估**」全链路。

6 大能力模块：

- 🤖 **AI 问答** — 苏格拉底式层层追问，多模态输出（文字 / 图片 / 短视频）
- 📋 **课程智能生成** — 头脑风暴 → 计划书 → 9 + 1 件完整课程包
- 🧠 **学习画像与路径** — 多维行为采集 + 个性化推荐 + 动态路径规划
- 🤝 **多 Agent 协同** — 任务链传递 + 交叉验证 + Judge 仲裁
- 📊 **数据可视化大屏** — 教师端管理 + 学生学情全景
- 🛡 **知识库与安全体系** — RAG 防幻觉 + Audit 4 层防御 + 循环迭代

## 系统长什么样（6 层架构）

```
┌─────────────────────────────────────────────────────────────────┐
│ L1  体验层        html/*.html + js/*.js + css/*.css             │
│     原生 HTML/JS，不引前端框架（可现场演示 + 可追溯）              │
├─────────────────────────────────────────────────────────────────┤
│ L2  API 层        app/api/*.py (FastAPI routers)                 │
│     /api/auth  /api/teacher  /api/profile  /api/health  ...     │
├─────────────────────────────────────────────────────────────────┤
│ L3  教学编排层    app/services/tutor_engine/*                    │
│     ContextAggregator → LLM → HallucinationGuard                │
│                       → LinkRecommender → ResponseComposer       │
├─────────────────────────────────────────────────────────────────┤
│ L4  智能体层      app/agents/* + LangGraph 多 Agent 编排        │
│     Profiler / Planner / Socratic / Recommend / Audit / Judge   │
│     通信协议: AgentEnvelope (trace_id + role + payload)          │
├─────────────────────────────────────────────────────────────────┤
│ L5  数据与记忆层  app/services/repository/* + db.py              │
│     SQLAlchemy 2.x async ORM (SQLite 本地 / MySQL 生产)         │
│     + Qdrant 向量库 + 长记忆 (agents.py)                        │
├─────────────────────────────────────────────────────────────────┤
│ L6  外部服务层    app/services/llm/* + kb/* + tts/* + asr/*      │
│     MiniMax / 讯飞 / Whisper / 可灵 / CogVideo 多 Provider 适配  │
└─────────────────────────────────────────────────────────────────┘
```

每层边界清晰，评委可逐层追问；trace_id 贯穿 L2→L6，出问题可秒级定位。

详细版见 [docs/00-比赛架构图.md](docs/00-比赛架构图.md)，
数据流主链见 [docs/01-数据流图.md](docs/01-数据流图.md)。

## 4 步开始

### 步骤 1 — 安装依赖

```bash
pip install -r requirements.txt
```

### 步骤 2 — 准备环境变量

```bash
cp .env.example .env
# 编辑 .env 填入 MiniMax API_KEY / 讯飞凭据 / JWT_SECRET 等
```

### 步骤 3 — 初始化数据库

```bash
python main.py        # 首次启动会自动建表 + 加载演示种子
# 或显式: alembic upgrade head
```

### 步骤 4 — 打开浏览器

访问 `http://127.0.0.1:8000/`，从 `hub.html` 进入。

> 遇到问题先看 [docs/04-技术问答.md](docs/04-技术问答.md)，
> 部署上线看 [docs/15-生产部署.md](docs/15-生产部署.md)。
